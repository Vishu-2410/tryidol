# Offline Document Viewer – Tryidol Assignment

A 100% offline-first document viewer built using React and Vite.  
All supported files are processed locally in the browser, ensuring privacy and zero server uploads.

---

## 🚀 Features

- 📂 Supports multiple document formats:
  - PDF
  - Excel (XLS / XLSX)
  - Word (DOCX)
  - RTF
  - Markdown
  - Images (PNG / JPG / JPEG)
- 🛡️ Privacy-first architecture (no server-side uploads)
- ⚡ Optimized rendering for smooth performance
- 🌐 Fully client-side and works offline

---

## 🛠️ Tech Stack

- React
- Vite
- pdfjs-dist
- xlsx
- docx-preview
- Client-side FileReader API
